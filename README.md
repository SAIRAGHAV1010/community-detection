# Dynamic Community Detection in Evolving Networks

## Overview

This project presents a Dynamic Community Detection System designed to analyze and identify communities in evolving networks. Unlike traditional approaches that focus on static networks, this system captures how communities change over time by analyzing temporal interactions between nodes. The project aims to provide meaningful insights into network evolution, including community formation, growth, merging, splitting, and disappearance.

The system is evaluated using the Yelp Dataset and demonstrates effective community detection through temporal graph analysis and network visualization.

---

## Features

* Dynamic community detection in evolving networks
* Temporal graph construction using time-window analysis
* Detection of community evolution over different time periods
* Community visualization and network analysis
* Modularity-based evaluation of community quality
* Scalable framework for medium to large datasets
* Interactive graphical representation of detected communities

---

## Dataset

The project uses the Yelp Academic Dataset, specifically review data containing:

* User ID
* Business ID
* Review Date

These attributes are used to construct temporal interaction networks and analyze community structures over time.
